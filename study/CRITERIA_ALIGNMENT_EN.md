## Important distinction

**Tests passed** = backend unit/integration-level service and SQLite persistence tested in this environment. **NOT verified yet** = user's iPhone run of v2, npm install over real network, Expo bundle and complete UI journey. **NOT done** = human-subject empirical experiment. No screenshots, participant records, usability ratings or effect sizes are fabricated.
