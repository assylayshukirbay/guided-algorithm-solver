# Package inventory and audit of Assignment 3 deliverables

The **source code and methods draft** are provided for project continuity, not as a claim that an empirical research study was conducted.

## Immediate runnable prototype deliverables
- React Native / Expo frontend with complete educational flow in `mobile/App.js`.
- Three foundation lessons with comprehension checks in `mobile/src/foundation.js`.
- Express REST API, lesson support, server-side scoring and transfer challenge endpoints.
- SQLite persistence with session, event and attempt tables.
- Ten passing Node.js automated tests in the build environment; run again on Windows.

## Academic package
- `Assignment_3_Methodology_DRAFT.docx`: methodology sections 1–6 (~1,300 words), Part 7 technical implementation, Part 8 alignment, references and appendices.
- `STUDY_PROTOCOL_EN.md`: scope, comparison groups, fairness and intended analysis.
- `MEASURES_AND_INSTRUMENTS_EN.md`: independent test forms, rubric, optional usability items.
- `CRITERIA_ALIGNMENT_EN.md`: mapping of Assignment 3 requirements to evidence and remaining steps.
- `FUNCTIONAL_TEST_PLAN_EN.md`: 12 manual tests and screenshot plan.
- `ACTUAL_TEST_RESULTS_TEMPLATE.csv`: deliberately blank testing evidence sheet.
- `DEFENSE_NOTES_EN.md`: brief oral defense explanation.

## Outstanding for a legitimate final submission
1. Complete a live run on an iPhone and record authentic screenshots and outcomes.
2. Upload the code to your own GitHub repository and add URL + commit ID.
3. Have the rubric, test forms, research design and protocol approved by the lecturer.
4. Obtain participant approvals, informed consent and real data if field collection is part of the actual submission stage; never invent participants or significance statistics.
5. Recheck the report against the official course marking sheet if it differs from the Assignment 3 requirements provided earlier.
